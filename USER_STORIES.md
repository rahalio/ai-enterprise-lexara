# Lexara — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### CDO / Head of Analytics

- As CDO, I want every “AI” proposal mapped to techniques and claim class, so that the investment committee stops funding rebrands.
- As CDO, I want trend-readiness scores, so that we fix cloud/data/API gaps instead of blaming algorithms.

### Enterprise architect

- As architect, I want API-first options surfaced when a technique is commoditised, so that we do not rebuild face recognition.
- As architect, I want narrowness warnings on solver/game-style approaches, so that sponsors do not expect cross-domain transfer.

### Procurement

- As procurement, I want RFPs blocked without audit IDs, so that vendors cannot skip definitional scrutiny.
- As procurement, I want rebrand classifications retained, so that repeat offenders are visible.

### LOB sponsor

- As sponsor, I want plain-language definitions beside my use case, so that I can defend the proposal without jargon theatre.
- As sponsor, I want examples like claims text+image assessment explained as techniques, so that expectations stay realistic.

### Risk / people partner

- As risk, I want job-impact narratives tied to technique scope, so that hype-driven fear or hype-driven denial are both avoided.
- As compliance, I want unstructured-data flags on initiatives, so that dark-data enthusiasm does not bypass privacy review.
